## 改了什麼

- 原本廣告區在頁首色帶下方（四張分類卡之前），現在整段搬到頁尾「授權與更新」卡片的正下方。

- 標示保留：卡片左上「廣告」字樣 + 「以下內容由 Google AdSense 提供，非本站編輯內容。」

## 區塊順序（部署後應該是）

1. 頁首色帶（H1 + 說明 + meta）
2. 四張分類卡
3. `bg-surface` 區塊：授權與更新卡 → 廣告卡（貼在它下面 24px）
4. footer
