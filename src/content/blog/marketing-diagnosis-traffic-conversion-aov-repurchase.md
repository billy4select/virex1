業績下滑時，很容易先想到幾個動作：增加廣告預算、多發內容、推出折扣活動。

這些方法可能有效，但如果還不知道業績是在哪個環節下降，直接增加投入不一定能解決問題。

對多數以訂單為核心的生意，可以先從四個方向拆解：流量、轉換率、客單價，以及顧客在一段期間內的購買次數。

> **快速結論：** 可以先用目前能取得、且口徑一致的資料建立基準。資料不足時，先把結論標示為初步觀察，不要假裝能精確定位原因。

## 先理解四個數字的關係

在一個簡化的情況下：

**營收 ≈ 訪客數 × 訂單轉換率 × 平均訂單金額 × 每位顧客的購買次數**

這是一個協助拆解問題的模型，不是所有商業模式都能直接套用。若有不同商品、不同通路、訂閱收入或線下成交，計算方式需要依照資料結構調整。

這裡也要分清楚「訂單數」和「顧客數」。同一位顧客可能下多筆訂單，回購分析應以顧客為單位，不能把訂單數直接當成回購人數。

## 第一步：先確認業績下降是不是真的

先確認比較期間是否合理。去年同期、上個月、活動期間與一般月份，可能受到季節、促銷與工作天數影響。

也要檢查營收是否扣除取消、退款，商品組合是否改變，以及線上與線下資料是否都納入。資料口徑不同，可能讓你以為業績下降，其實只是統計方式改變。

## 第二步：流量變少，還是流量來源改變？

如果訪客數下降，先看各個來源的變化：搜尋、社群、廣告、電子報、直接流量或其他通路。

如果總流量沒有下降，轉換率卻變差，也要檢查流量組成。新增通路可能帶來更多訪客，但這些人未必具有相同的購買意圖。

因此不要只看總流量，最好分來源、裝置與主要商品觀察。

## 第三步：訪客有來，為什麼沒有購買？

轉換率下降，可能是商品資訊、價格、信任、購買流程或流量品質出了問題。

可以先走一次完整的購買流程：從廣告或搜尋結果進入頁面，確認商品是否容易理解、價格與運費是否清楚、評價是否可信、付款方式是否方便，以及手機操作是否正常。

也可以整理客服與顧客留言，看看大家在購買前最常問什麼。這些問題往往能指出商品頁尚未解決的疑慮。

## 第四步：客單價為什麼改變？

客單價下降，可能是低價商品占比提高、促銷折扣增加、組合商品銷售減少，或顧客選擇了不同規格。

不要只把提高客單價理解成加購或提高免運門檻。先找出商品組合為什麼改變，再判斷是否有適合的搭配商品、方案或價格層級。

如果顧客不需要額外商品，硬推加購可能傷害體驗，也不一定能提高長期價值。

## 第五步：顧客買過之後，還會不會回來？

回購要放在合理的購買週期裡看。日用品可能幾週就有補貨需求，耐久財可能多年才再次購買。若用同一個 30 天回購率比較不同商品，容易得到錯誤結論。

可以先看：

- 首購顧客在合理期間內再次購買的比例。
- 從第一次購買到第二次購買，通常間隔多久。
- 不同商品、通路或客群的回購差異。
- 顧客是否因為售後體驗、品質或服務問題而沒有再回來。

回購不是單純靠發優惠券。產品是否持續有需求、體驗是否符合期待，通常更值得先理解。

## 用數據找出優先處理的環節

| 指標 | 上期 | 本期 | 需要追問的問題 |
|---|---:|---:|---|
| 訪客數 |  |  | 哪個流量來源改變？ |
| 轉換率 |  |  | 哪個商品、裝置或來源下降？ |
| 平均訂單金額 |  |  | 商品組合或折扣是否改變？ |
| 購買頻率 |  |  | 是否符合商品的回購週期？ |

先找出變化明顯、又有可能影響營收的環節。接著提出一個可驗證的原因，再安排一個範圍有限的檢查或調整。

不要一次同時改廣告、價格、商品頁與會員活動。即使結果變好，也很難知道是哪個改動帶來效果。

## 四個數字都正常，還要往哪裡看？

這個模型沒有涵蓋所有商業問題。如果四個指標沒有明顯變化，營收或利潤卻不理想，就要檢查商品供應、產品競爭力、價格結構、退款、通路抽成與固定成本。

也可能是流量與訂單沒有下降，但毛利變差。這時候只看營收會忽略真正的經營壓力。

行銷診斷的起點是找到變化，不是急著替變化找一個漂亮解釋。若要延伸檢查顧客需求，可以參考[用 AI 分析顧客評論](/blog/ai-batch-review-analysis/)；若想了解廣告漏斗的問題，可以看[廣告沒效果怎麼診斷](/blog/ads-not-working-diagnosis/)。
